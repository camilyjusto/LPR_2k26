# Atividades de Linguagem de Programação - 2026
*Curso Técnico em Desenvolvimento de Sistemas - Games*

---
> Todas as informações desse repositório são retiradas do material do professor: José Andery

## Objetivo geral do curso:

**"Resolver problemas utilizando as ferramentas de linguagem de programação"**

## A disciplina de Linguagens de Programação tem foco em:

- Desenvolvimento de raciocínio lógico
- Construção e análise de algoritmos
- Programação estruturada (C# e C++)
- Programação orientada a objetos (C#)
- Estruturas de dados fundamentais
- Integração com banco de dados (introdução)

## 📝 Competências
- Desenvolver **raciocínio crítico** para a compreensão de problemas do cotidiano e aplicação de ferramentas de programação para oferecer soluções.
- Conhecer e aplicar as **boas práticas de programação** em diversos cenários.
- Conhecer **ferramentas** utilizadas no cotidiano **de programação** e filtrar a viabilidade de aplicação de acordo com o cenário exposto. 
- Utilizar técnicas de **depuração de código** para identificar e corrigir erros e falhas em programas.

## 🧠 Habilidades
- Identificar problemas e **propor soluções lógicas**.
- **Resolver situação-problema** que envolva lógica de programação.
- **Documentar** e produzir códigos de **fácil manutenção** e reutilizáveis.
- **Trabalhar em equipe** e desenvolver códigos em conjunto. 
- **Utilizar ferramentas de controle de versão** para gerenciar o desenvolvimento colaborativo de software em equipe.
- Listar e planejar as **etapas do desenvolvimento de um sistema**.
- Utilizar **técnicas de design** e implementação de interfaces de usuário intuitivas e eficientes.
